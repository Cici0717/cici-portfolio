# Cici 的探索小花园

AI 产品、交互设计与日常好奇心的个人作品站。

## 在线访问

GitHub Pages 地址：https://cici0717.github.io/cici-portfolio/

## 内容

- 精选作品：经营助手、记得·关系记忆、衣研；包含源码与演示链接。
- 更多探索：壁纸生成器、Agent 工作台、业务拆解工具，以及北京地铁足迹源码入口。
- 六个公开项目的真实首页截图，可点击放大；截图采集于2026-10-28。
- 作品筛选与设计思考弹窗。
- 关于我、探索地图、做事方式。

## 实现与维护

使用原生 HTML、CSS、JavaScript，无需安装依赖或构建。浏览器直接打开 `index.html` 即可。

GitHub Pages 使用 `main` 分支的根目录发布。六张截图内嵌在 `index.html` 中，网页不依赖额外图片路径。修改页面后提交，Pages 将自动更新。原始截图本地另存，便于后续更新。

外部字体无法加载时使用系统字体，主要内容与交互不依赖字体服务。

## 作品边界

经营助手与工作台使用虚构数据及脚本化交互；关系记忆公开 lite 版使用本地规则，没有调用大模型；衣研为静态网页工具；业务拆解默认演示模式。截图来自各自实际公开页面，不代表真实用户验证或生产能力。北京地铁没有已核实的公开演示，只链接源码。“吃什么”仅作为开源学习入口，并保留原项目来源，不当作独立原创成果。

页面未包含私人电话、邮箱或简历文件。
