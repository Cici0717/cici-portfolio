# Cici 的探索小花园

AI 产品、交互设计与日常好奇心的个人作品站。

## 在线访问

GitHub Pages 地址：https://cici0717.github.io/cici-portfolio/

## 内容

- 精选作品：经营助手、记得·关系记忆、衣研；包含源码与演示链接。
- 作品筛选与设计思考弹窗。
- 关于我、探索地图、做事方式。

## 实现与维护

使用原生 HTML、CSS、JavaScript，无需安装依赖或构建。浏览器直接打开 `index.html` 即可。

GitHub Pages 使用 `main` 分支的根目录发布。修改 `index.html` 并提交后，Pages 将自动更新。`.nojekyll` 表示直接发布静态文件。

外部字体无法加载时使用系统字体，主要内容与交互不依赖字体服务。

## 作品边界

经营助手使用虚构数据与模拟执行；关系记忆公开 lite 版使用本地规则，没有调用大模型；衣研为静态网页工具。项目配图为示意插画，不是产品截图。尚未验证的用户与业务成效不作为既有成果展示。

页面未包含私人电话、邮箱或简历文件。
