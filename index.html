PROJECT 03 / EVERYDAY DECISIONS

衣研 · 网购小参谋

面向看不懂材质标签、拿不准网购尺码的人，把成分信息、尺寸比较与个人穿着记录连接起来。用已知合身的衣物作参照，让每次选购有据可比。当前为静态网页工具，尚未验证退货率等业务效果。

信息设计尺寸比较生活工具

03 / a little about me

理性地拆解，
感性地观察。

Hello, I'm Cici ☺

你好，我是 Cici，重庆大学软件工程硕士在读。我的关注点在技术能做到什么，以及人真正需要什么的交汇处。

从可视分析研究，到企业 AI 搜索、Coding Agent 相关实习，再到自己的小工具，我一直在练习同一件事：把模糊的问题拆清楚，让想法变成可以体验、可以检查的东西。

我喜欢从具体场景出发：一次交流后忘记的约定、一张难读的成分表、一个让人不敢点下去的 AI 操作。小问题，也值得认真设计。

05 / how i like to work

我想坚持的做事方式

用可检查的过程，代替抽象的自我评价。

01 / THINK CLEARLY

先把问题问对

谁在什么场景遇到困难？先明确任务和边界，再讨论功能。

02 / LEARN BY MAKING

边做边学，留下证据

把新知识用进一个小闭环，用失败和反馈修正理解。

03 / EXPLORE ALTERNATIVES

给想法一个可体验的形状

从交互原型开始，讲清为什么这样设计、舍弃了什么。

04 / MAKE IT SHARED

让判断能被讨论

把目标、取舍和验收条件写清楚，让协作有共同的参照。
